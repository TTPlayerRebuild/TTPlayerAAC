# AAC 保存兼容与 FAAD2 2.11.4

日期：2026-10-19。原件仍以 SHA-256 `49195708ba9b942edd8215ffcb4e5db73a1548b0c02a5e2b11960ea12af69135` 为基准；工作区顶层 AddIn 中较早的重建 DLL 不充当原件。

## 修改

1. MP4 标签和封面先暂存，最后一次释放 Reader 时统一保存，恢复原插件的提交时机。新增可选 `MetadataCommit` 查询接口（IID `3AB643C1-D8A4-4D49-9CBB-EF196B04B6E7`）供重建宿主获取真实结果；原 Reader/Metadata 虚表未变。显式提交是终结操作，重复调用返回原结果，失败后析构不重试。
2. 旧播放器的直接文件流可能不实现 `IStream::Commit`；只对 `E_NOTIMPL` 与 `STG_E_INVALIDFUNCTION` 兼容放行，真实磁盘错误继续传播。短写不能视为成功。
3. 新 moov 先作为末尾 free 完整写入，再切换类型并退役旧 moov；中途失败恢复旧 moov，将追加区退回 EOF-sized free。即使宿主不支持 SetSize，仍能重开且只有一个有效 moov。保存前检查文件长度未被其他对象修改。没有承诺掉电/持续介质故障下的原子性。
4. 信息/播放只读标志抑制写入能力；已提交对象不能重新打开或继续修改。短读流在非 EOF 时继续补读，真实 EOF/读取错误不吞掉。
5. 未知时长使用宿主 ReferenceDuration；已解析的精确时长优先。

## 解码库更新

采用 [FAAD2 2.11.4](https://github.com/knik0/faad2/releases/tag/2.11.4)，固定归档 SHA-256：
`f4d3630ffdbf17ef17e358007c91d6b51e487de0771dd2d3b3e994d4f0ad81ff`。

2.11.4 初始化返回 AAC 核心声道数，显式或隐式 PS 的单声道核心需要在打开设备前确定双声道输出。现恢复 ASC 的 PS 标记，并用有限的预解码解析隐式 SBR/PS；裸 AAC/直播保留预解码产生的 PCM。两组纯单声道样本由旧版重复双声道改为真正单声道，帧数和单声道数值均未丢失。

FAAD2 的命令行 gapless 改进不自动覆盖本插件的自有 MP4 reader；本轮没有新增 edit-list/iTunSMPB 裁剪。既有 Nero 编码后端未被替换。

## 验证

测试代码和私有样本只在 `rebuild/tests/audio_plugins_fix_20261019`，不上传、不进入 Action。

- Windows 11：14 组升级前后完整解码及 0/中/末定位，另有两组标签/PNG 封面修改、删除、关闭重开，共 44 项记录通过。单声道修正单独比较帧数和声道，不把输出字节数减半误判为截断。
- AAC 保存 15 组，包括未实现 Commit、磁盘满、写入错误、5 个位置的短写/失败；均核对唯一 moov、原音频 SHA-256、重新打开、重复提交与析构不重试。
- 额外 40 组：末尾 size=0 的 mdat/moov 保存及回滚；13 字节分段读取；AAC-LC/HE-AAC v2 本地和未知长度 ADTS 输出一致，参考时长及不可定位行为正确。
- XP SP3、Win7 SP1：共同运行 AAC/OGG/APE 联合 103 项，均 `failures=0`；82 个 PCM、写回文件及封面结果哈希与 Windows 11 相同。
- Windows 11 原版 5.7.9 与重建版实际加载此 DLL，AAC 播放进度分别约 3711/3730 ms，正常关闭、无错误对话框。虚拟机宿主测试另见综合报告。

本轮 DLL：373248 字节，SHA-256 `041999507e260d2c8e828b0223adbbb973e4ea287080bf9ba832de9d280e09d9`；XP/Win7 导入审查为 3 个系统 DLL、91 个导入。日期版本为 2026.10.19，库不要求安装 VC 2012。

## 保留边界

ADIF、Main/SSR/LD、MP3-in-MP4 尚缺完整的代表性对照矩阵；分片 MP4 元数据仍只读；单封面/60000 字节限制仍按原 ABI 保留；不可定位 ADTS 不代表任意 MP4 网络流。升级核心后不承诺所有样本与原 FAAD2 2.7 逐字节相同。
